# Dragon Adventures (public runtime)

Offline-friendly Chromebook dragon adventure. This repository contains **compiled runtime assets only** (no game source, workbook, photos, wishlist, or private intake).

Playable title: **Dragon Adventures** v0.9.2. Repository path keeps `dragon-master-trilli` so bookmarks and saves continue to work.

## Play

https://codekay1.github.io/dragon-master-trilli/

On first visit while online, wait until the HUD shows **Offline ready**, then bookmark or install. After that you can cold-launch offline.

ZIP under `download/` is a static-file mirror — prefer the HTTPS Pages URL over `file://`.

## Controls

- **W** forward, **S** back, **A** left, **D** right (relative to camera)
- **C** / **Home** (or touch **Level view**) recenter pitch
- Mouse look; Minecraft-style interaction; basic touch support
- Ride: mount a dragon, **Q** fire breath (tap or hold), **E** dismount beside the dragon
- **F** or right-click feeds a nearby dragon (a tamed friend gets a toast)
- **I** / bag icon opens the backpack inventory

## Privacy & saves

- No accounts. Saves stay in this browser for this site origin only.
- Export JSON backups from the pause menu.
- No analytics; gameplay does not require network after the first successful cache.
